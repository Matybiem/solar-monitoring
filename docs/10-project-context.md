# Contexto del proyecto

Solar Monitoring es un proyecto personal de portafolio para monitorear una instalación solar y sus baterías. Se encuentra en etapa de planificación.

## Fuente de verdad

- [SRS](SRS.md): requisitos, restricciones y criterios de éxito.
- [Arquitectura](03-architecture.md): componentes propuestos y decisiones pendientes.
- [Registro de decisiones](07-decisions-log.md): decisiones iniciales y temas sin resolver.
- [Hoja de ruta](08-roadmap.md): orden de trabajo propuesto.

El stack web aceptado es React, TypeScript y Vite; el SRS especifica Firebase Realtime Database para el MVP. No asumir que existen código funcional, infraestructura desplegada ni mediciones verificadas.

Las recomendaciones deben distinguir hechos, supuestos y decisiones pendientes; no inventar resultados ni dar por implementadas funcionalidades.
