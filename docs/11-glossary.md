# Glosario

| Término | Significado |
| --- | --- |
| ESP32-C3 | Microcontrolador con conectividad inalámbrica. |
| INA219 | Sensor de corriente y tensión utilizado en el diseño previsto. |
| IoT | Internet de las cosas: dispositivos conectados que intercambian datos. |
| Telemetría | Datos de medición y estado transmitidos remotamente. |
| SoC | Estado de carga estimado de una batería. |
| RSSI | Indicador de intensidad de señal recibida. |
| MVP | Versión inicial con el alcance definido en el SRS. |
| SRS | Especificación de requisitos de software. |
| ADR | Registro de una decisión de arquitectura y su contexto. |
